# Systemne Liderstvo Landing

Vite + React лендинг для програми «Системне лідерство».

## Деплой на Vercel

1. Завантажити всі файли з цього архіву в GitHub-репозиторій.
2. У Vercel імпортувати репозиторій.
3. Settings:
   - Framework Preset: Vite
   - Build Command: `npm run build`
   - Output Directory: `dist`
   - Install Command: `npm install`
4. Deploy.
